Como funciona?

  • O backup será salvo em um arquivo no seu computador.
  • O arquivo contém os dados armazenados pelo sistema.
  • Você pode guardar o arquivo em um pendrive, HD externo ou nuvem.
  • Para recuperar os dados, basta selecionar o arquivo de backup.
  • A restauração substituirá os dados atuais pelos dados do backup.
